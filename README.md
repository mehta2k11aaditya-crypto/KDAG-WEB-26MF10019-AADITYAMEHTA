# KDAG Landing Page Project

A responsive landing page created as part of the KDAG task/bootcamp.
The project demonstrates the use of HTML, CSS and JS to build an interactive and visually appealing web pages

## Features

- Responsive Landing Page Design
- Navigation bar with internal links
- Information sections about the bootcamp
- Registration form
- Form validation using Javascript
- Styled as per KDAG Theme using CSS

## Technology used

- HTML 5: Structure and Content
- CSS 3: Styling
- JavaScript: For Validation of form

## Notes

- This project was built from scratch to practice frontend web development concepts and demonstrate the implimentation of complete landing page using HTMl, CSS and JavaScript
